## Substrate assumptions

- paideia-os R48 substrate closed: KIND_PDXFS_FILE = 0x195,
  KIND_PDXFS_TXN = 0x196 (commit 411ad0e). Derived-kind + witness
  only; the sys_pdxfs_txn_begin / sys_pdxfs_txn_commit /
  sys_pdxfs_txn_abort / sys_pdxfs_readdir / sys_pdxfs_mkdir /
  sys_pdxfs_stat syscalls remain to land at R42 substrate expansion.
- libpdx-argv M2 landed: FlagSpec, StdVocab, find_flag_by_id, typed
  flags. cp.M2-001 migrates from M1's byte-compare walk to
  find_flag_by_id via CpFlags mirror slots.
- libpdx-cap M2 landed: cap_manifest_verify, cap_pack_narrowed,
  cap_unpack_checked. Signed-inode helpers (re-sign under invoker
  user_sk) land at libpdx-cap.M3; cp.M2-002/M2-003 ship a shape-in-
  place stub that gracefully degrades.
- paideia-as ≥ v0.33 remains the required toolchain floor.

## Shape-in-place components (substrate-blocked)

The following pieces ship shape-only bodies at M2 because the
substrate they rely on has not yet landed. Each is designed so the
substrate-landing patch is a body edit (no restructure):

| Component                                    | Substrate blocker                    | Body-edit landing site                          |
|----------------------------------------------|--------------------------------------|-------------------------------------------------|
| `Pdxfs::pdxfs_readdir`                       | sys_pdxfs_readdir dispatch entry     | R42 substrate expansion (paideia-os kernel)     |
| `Pdxfs::pdxfs_mkdir`                         | sys_pdxfs_mkdir dispatch entry       | R42 substrate expansion                         |
| `Pdxfs::pdxfs_stat`                          | sys_pdxfs_stat dispatch entry        | R42 substrate expansion                         |
| `Pdxfs::pdxfs_txn_begin / _commit / _abort`  | sys_pdxfs_txn_* dispatch entries     | R42 substrate expansion                         |
| `Walk::walk_entry_todo`                      | dirent record format + readdir body  | walk_recursive body edit (parse walk_entry_buf) |
| `SignedInode::preserve_at_destination`       | libpdx-cap.M3 signed-inode helpers   | signed_inode.pdx body edit (call libpdx-cap M3) |
| `Undo::record_over_existing`                 | PdxFS v1 undo-record journal syscall | undo.pdx body edit (call sys_pdxfs_undo_write)  |
