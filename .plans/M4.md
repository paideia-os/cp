## Test-runner surface (design-frozen at M4)

Each issue lands one Markdown spec under `tests/`. Every spec
enumerates:

1. Test matrix rows (fixture + invocation + assertions).
2. Fixtures + cap-scope conventions.
3. Observation hooks — cp `.bss` counter symbols the harness reads
   via loader symbol lookup. No test-only build variant needed.
4. Cross-row invariants (I1..IN).
5. Pass criteria + substrate-landing gates.

**Total rows across the three specs.** M4-001: 5 rows (Rows 1-5).
M4-002: 6 rows (Rows 1-6). M4-003: 7 rows (Rows 1-7). = 18 rows.

**Rows that pass today.** M4-001 Row 1; M4-002 Row 1, Row 6;
M4-003 Row 2, Row 3. Every remaining row is shape-in-place — the
observation-hook assertions compile against the current cp symbol
table; the byte assertions lift when the substrate gate lifts.

## Cross-row observation hooks (union across specs)

The M4 harness reads these cp `.bss` symbols via loader symbol
lookup — every one is already `pub let mut` in the M2/M3 source:

- `CopyFile::bytes_copied` (src/copy.pdx)
- `CopyFile::fd_src`, `CopyFile::fd_dst` (src/copy.pdx — for
  liveness assertions on the error branches)
- `Dispatch::chosen_arm` (src/dispatch.pdx)
- `Walk::entries_visited`, `Walk::fd_src_dir` (src/walk.pdx)
- `CpPipe::pipe_binds`, `CpPipe::pipe_emits`,
  `CpPipe::pipe_bind_errors`, `CpPipe::pipe_emit_errors`
  (src/pipe.pdx)
- `CpAudit::audit_commit_calls` — plus the M3 audit-id slot
  (src/audit.pdx)
- `CpElevate::elevate_calls`, `CpElevate::elevate_ok`,
  `CpElevate::elevate_refused`, `CpElevate::cp_elevate_req_buf`,
  `CpElevate::cp_elevate_reply_buf` (src/elevate.pdx)
- `SignedInode::preserve_calls`, `SignedInode::preserve_degrades`
  (src/signed_inode.pdx)
- `Undo::undo_records_written`, `Undo::undo_reason` (src/undo.pdx)
- `CpFlags::flag_verbose_seen`, `CpFlags::flag_recursive_seen`,
  `CpFlags::flag_dry_run_seen`, `CpFlags::flag_over_existing_seen`
  (src/flags.pdx)

## Deferred to a future M4.5 (not in cp.M4 issue set)

- Argv-surface fuzzer against the three cp-owned flags + two
  positionals.
- Concurrent-cp invocation matrix (two cps writing to the same
  dst-parent — depends on the PdxFS v1 contention model at
  R42-PREP-004).
- Mid-copy quota exhaustion (write returns `-EDQUOT` inside the
  outer TXN — currently degenerates into M4-001 Row 5 shape).
- `--elevate-timeout` per-invocation duration override (adds a
  new cp flag + a REQ-frame per-invocation duration field).
- Elevate-widened cap-tail signing (would require the widened
  window to be treated as a "sign-as-granter" capability at
  libpdx-elevate.M4).
